# Çocuk Profili — örnek

o dosya sürüm kontrolüne girmez.

Bilinmeyen alanı silme, `bilinmiyor` yaz — kurul eksikliği görmeli. Doğruluğundan emin
olmadığın bir ölçümün yanına `[doğrulanmalı]` etiketi koy; kurul o değere dayanan sonuç
kurmaz, önce doğrulanmasını ister.
